# Working agreement

Read and apply https://github.com/Living-Proof-Labs/collaboration-guidelines/blob/v3.0.0/AGENTS.md
and its relevant linked procedures at that same version.

Use isolated checkouts, focused draft pull requests and `task setup`, then
`task verify`. Keep collection, aggregation, grading and rendering separate.
Retain original results and provenance. Never imply robot safety certification.
Consumers need neither a checkout nor Task. Python environments must respect
system-managed Python. Release packages through the shared release workflow.
