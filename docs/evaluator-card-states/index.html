Evaluator cards: fixed width, hover, and a selected state

Titles are used exactly as the descriptor supplies them, with no “Evaluator” suffix. Cards keep a fixed width so a longer row stays predictable. Hover makes the control feel clickable, and the selected card is visually tied to the details below.

Proposed card states

Width is 11.25rem (180px). Speaking still means “this evaluator has something to say”. Selected is a separate state, used only when that card is open, so the panel below is clearly theirs.

Default

Quiet, with the teal check. Transparent border, ready to receive hover.

Hover

Background and border shift to --bg-muted / --border-strong. Cursor is pointer. Keyboard uses the existing --focus ring.

Speaking, not open

The --speak tint still flags a finding. Details stay closed until the card is clicked, so this is not the selected state.

Selected

Teal accent border and a connector into the panel. The panel heading uses the same accent, so the two read as one control.

Proposed, in a report · desktop

Four evaluators, left-aligned at the fixed width. Scenario is open. The other marks stay quiet. When every evaluator passes, nothing is selected and every panel stays closed.
